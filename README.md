# Combo Rush - 2D Match-3 Mobile Game

A 2D Match-3 / linking puzzle game developed in Unity 6 (URP), featuring a responsive 9:16 vertical mobile screen architecture.

## Features

- **Grid Logic:** 6x8 dynamic grid and screen centering (offset) system.
- **Snap-to-Cell Interaction:** Fluid LineRenderer connection that snaps to "jelly" centers.
- **Dynamic Scoring & Combo:** Length-based scoring bonuses and dynamic "Punch Scale" UI animations.
- **Responsive UI:** Full compatibility with all screen aspect ratios via Canvas Scaler (1080x1920).
